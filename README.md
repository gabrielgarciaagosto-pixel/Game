# Death is my Business

Android-first isometric mortuary management game built with React, TypeScript, Vite, React Three Fiber, Zustand, and Capacitor.

## Scripts

- `npm run dev` — local web preview
- `npm run build` — production web build
- `npx cap sync android` — sync web assets into the Android project

## Stations

- **Embalming Table** — proximity pour fluid mixing with S+–F ranking
- **Cremation Retort** — stepped temperature burns, stirs, and 3-tool sweep
- **Urn Processor** — magnetic metal recovery, cremulator, funnel pour
- **Chapel & Showroom** — buy merchandise, place floral sprays, finalize services
